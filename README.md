# Lattice Kaná — descargas

Instaladores de la aplicación de escritorio **Lattice Kaná** (Sintérgica AI):
macOS (Apple Silicon) y Windows (64 bits). Cada release trae el DMG, el EXE,
las sumas SHA-256 y el feed que usa la propia aplicación para actualizarse.

La descarga oficial está en <https://lattice.sintergica.ai/descargar>.

Este repositorio no contiene código: solo publica versiones.
